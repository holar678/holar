# 玩法借鉴调研:小丑牌和同类游戏

2026-11-17。目的:让"组合"更有深度,既有简单好凑的组合,也有复杂、能打出很高分的组合。

只借鉴机制,不照搬任何游戏的名字、卡面、美术和具体数值。

## 一、先看我们已经有什么

《夜市一条街》的骨架其实已经和小丑牌很像:

| 小丑牌 | 我们 | 状态 |
|---|---|---|
| 筹码 × 倍率 | 流水 × 人气 = 热度 | 已有 |
| Boss 盲注(规则提前公布) | 大考夜 | 已有 |
| 利息(没花的钱生钱,有上限) | 利息 | 已有 |
| 跳过盲注换标签 | 跳过平常夜换奖励 | 已有 |
| 赌注难度阶梯 | 难度 8 档 | 已有 |
| 5 个小丑栏位 | 5 个秘诀栏位 | 已有 |
| ×倍率小丑 | 5 个稀有秘诀 | 已有 |
| **出牌的牌型**(对子、顺子、同花……) | 只有 10 种两两相邻的招牌搭配 | **缺"通用牌型"** |
| **星球牌**(某个牌型永久升级) | 没有 | **缺** |
| **成长型小丑**(越打越强) | 没有,秘诀拿到手就固定 | **缺** |
| **改规则的小丑**("所有牌都算人头牌") | 秘诀几乎都是"+15% 售价"这类加数值的 | **缺** |
| **重新触发、复制**(再算一次、抄隔壁的效果) | 没有 | **缺** |
| **卡牌增强**(给某一张牌镀金、加闪) | 只有同名升级 | **缺** |
| **计分演出**(一项一项往上加,数字跳) | 夜里有"人气 +0.1"飘字,收摊只有一行字 | **偏弱** |

结论:框架不缺,缺的是**让组合变深的那几层**。现在的问题是:
1. 秘诀大多是全局加百分比,拿哪个都差不多,不会让人觉得"这局我走某某流派"。
2. 招牌搭配是固定的两两组合,要记表,而且没有"简单就能凑"的那一档。
3. 一局里没有越滚越大的东西,后半局缺少"养成"和"爆分"的快感。

## 二、调研了哪些游戏、各借什么

### 1. 小丑牌(Balatro):核心参考

- **牌型给底分,小丑放大它**。玩家最常打的是同花、顺子这类基础倍率 4 左右的牌型;开发者在设计说明里提到,一个简单的"+10 倍率"往往比一个随机的"×1.5"更有用。**启示:简单的加法要够用,乘法留给成型的构筑。**
- **乘法放最后**。加倍率在前、乘倍率在后,所以同样的东西换个顺序分数差很多。我们街道上摊位的先后顺序已经天然承担了这层意思。
- **成长型小丑**:每出一次某牌型就永久 +1 倍率,这类小丑给人"养大它"的感觉,也带来"现在卖掉还是继续养"的取舍。
- **改规则的小丑**:把"同花要 5 张"改成 4 张、让所有牌都算某种花色。它们本身不加分,但会让一套构筑突然成型,这是"复杂组合"的主要来源。
- **星球牌**:选定一种牌型永久升级,这一局就有了方向("我这局主打同花")。
- **评价里的缺点**:有评论认为计分的中间过程不容易看清;也有玩家说普通难度下经常是"勉强过关",很少觉得自己很强。**启示:要把每一项加成的来源演给玩家看;要留几条能真正"爆分"的路线。**

### 2. 《你有饼吗?》(Omelet You Cook):同是食物题材的小丑牌式游戏

据报道是两人开发,上线后好评率很长时间保持在 100%(这个数字我没有核实)。玩法是往锅里摆食材凑分:
- **同类食材连续放会连击**(蔬菜挨蔬菜、海鲜挨海鲜),**简单、一眼就懂**。
- 辣椒"点燃一切"、奶酪"叠倍率"这类**带性格的规则**。
- **放下就不能拿起来**,摆放本身就是决策。
- 看起来没用的食材(破蛋壳)配上特定道具会变强:**废牌翻身**。

**启示:我们最该学它的"同品类连摊"。** 我们的品类配色(小吃红、甜品紫……)本来就让玩家一眼能看出同品类,连在一起应该有奖励。

### 3. 幸运房东(Luck be a Landlord):老虎机上的相邻组合

- 符号**挨着就互相触发**,有的符号会"吃掉"相邻符号并永久变强。
- 玩家抱怨后期被没用的符号稀释,所以"删掉一个符号"本身就是奖励。
- 开发者提过,一个符号底价只加 1 块钱,就能大大改变好不好玩。**启示:小数值也值得认真调。**

**启示:可以加"吞并"类摊位,以及"拆摊换钱"。**

### 4. Ballionaire(弹珠台肉鸽):触发链

- 弹珠碰到 A,A 触发相邻的 B,一路连下去,很爽。
- 评测的主要批评:**"触发"到底指什么没讲清楚,玩家会因为猜错规则毁掉一局。**

**启示:做"触发"类效果时,说明文字必须写清"什么时候、对谁、加多少"。**

### 5. 其他可参考的

- **杀戮尖塔**:地图上自己选路线(普通、精英、商店、事件)。我们可以让玩家在两个夜晚之间选下一晚去哪条街。工作量大,先不做。
- **超级自动宠物**:"开场时"、"每卖第 5 单时"、"收摊时"这类**时机触发**,很适合做支援摊。
- **背包乱斗**:物品只加成某个方向的格子(比如只加成下方一格),让摆放变成拼图。

## 三、建议做的事(按"效果 / 工作量"排序)

### A. 街型:我们自己的"牌型"(最推荐)

开张时自动识别街面上的形状,每种街型给一份**基础人气**。这是"简单组合"的一档,不用记表,看颜色就能凑:

| 街型 | 条件(只看靠街摊位) | 基础人气 | 难度 |
|---|---|---|---|
| 连摊 | 同一侧连续 3 个同品类 | +0.3 | 简单 |
| 长连摊 | 同一侧连续 5 个同品类 | +0.8 | 中 |
| 对门生意 | 街两边同一排是同名摊位,至少 2 对 | +0.4 | 简单 |
| 百货齐全 | 5 个品类都有 | +0.5 | 中 |
| 连锁店 | 3 个同名摊位(不叠放) | +0.4 | 中 |
| 金字招牌街 | 2 个以上 3 级摊位 | +0.6 | 难 |

同时能成立多个街型,人气叠加。招牌搭配继续保留,它属于"复杂组合"一档。

**配套:品类升级(相当于星球牌)。** 秘诀三选一里偶尔出现"小吃街升级":这一局所有小吃摊售价 +1、连摊的人气 +0.1。可以叠,让一局有方向。

工作量:规则约半天到一天,界面要显示识别到的街型(白天顶栏、开张时飘字)。需要重新定目标。不需要新美术,街型可以用文字横幅。

### B. 成长型秘诀(推荐)

拿到以后越用越强,结束时可以选择保留还是换掉。示例:

- **老主顾**:每晚收摊时,人气起步值永久 +0.05(上限 +1)。
- **口碑发酵**:每有一位顾客买满,这个秘诀永久 +¥0.2 每单。
- **夜猫子**:连续不跳过夜晚,每晚 +5% 售价;跳过一次就清零。
- **专注经营**:每晚只要没有换货,售价永久 +3%。

工作量:规则小。每个新秘诀要一个图标,需要美术出图(或者先用代码画的占位图)。

### C. 改规则的秘诀(推荐,用来做"复杂组合")

这类秘诀本身不加分,但会让某套构筑突然成型:

- **混搭**:甜品和饮品算作同一个品类(帮助凑连摊、专卖街)。
- **隔空搭配**:招牌搭配中间隔一格也算数。
- **双面摊**:里排摊位也能卖东西,但只卖给路过的一半顾客。
- **越吃越渴**:所有小吃都会让顾客口渴(烤串、小龙虾的倍数不变)。
- **复刻**:复制它右边那个秘诀的效果(放在秘诀栏里,顺序有意义)。

工作量:每条的规则和测试要单独想,中等。图标同上。

### D. 摊位加料(相当于卡牌增强)

某些奖励不是秘诀,而是"给一个摊位加料",永久跟着这个摊位,叠放升级时保留:

- **金字招牌**:这一摊每卖一单 +¥2。
- **霓虹灯箱**:这一摊每卖一单人气 +0.02。
- **回头客专座**:这一摊每晚第一单再算一次(重新触发)。
- **老汤底**:这一摊售价 ×1.5。

摊位角上画一个小标记。来源:大考奖励、跳过平常夜的奖励、每日挑战。

工作量:中等,存档要多存一个字段,摊位画法加标记,战书编码要兼容。

### E. 收摊计分演出(便宜但很重要)

现在收摊只显示"流水 ¥120 × 人气 2.3 = 热度 276"一行字。改成一项一项往上跳:

1. 流水的数字滚到最终值;
2. 人气从 ×1.0 起,按来源逐条加:招牌搭配 +0.4、口渴连击 +0.6、买满 +0.3……(以后再加街型);
3. 稀有秘诀逐个乘上去,每乘一次数字放大、抖一下、配音效;
4. 最后算出热度,和目标比较。

这正好解决了小丑牌被批评的那个问题:玩家看不清分数从哪来。工作量:界面半天左右,不改规则,不需要重新定目标。

### F. 触发类支援摊(可选)

- **铜锣**:相邻摊位每卖第 5 单,周围所有摊位当场再吸引一次路人。
- **大喇叭**:只加成它正下方(靠街尾方向)那一格,加成翻倍。
- **夜宵大排档(吞并)**:每晚收摊吃掉旁边一个 1 级摊位,永久继承它售价的一半。

工作量:中到大,每个都要新美术。

### 暂不建议

- **秘诀之间按顺序结算**(小丑牌那样从左到右):手机上拖动排序太麻烦,摊位顺序已经有这层意思了。C 里的"复刻"只是一个轻量版。
- **地图选路线**:工作量大,而且会把一晚的节奏拉长。

## 四、要注意的风险

1. **钱和热度要继续分开**。所有新的倍率只加在人气上,不变成钱,否则会重演"钱滚雪球"的老问题。
2. **每加一层都要重新定目标**。现在的目标已经怀疑偏松(自动试玩的中位数是目标的 2~5 倍),加街型和成长秘诀后还会更松。最好先有真人试玩数据,再一次性调。
3. **说明文字是小屏幕上最大的成本**。每条秘诀最好一行讲清楚,写明"什么时候、对谁、加多少"。
4. **新秘诀和新摊位都要美术**。A、E 不需要新图,可以先做;B、C、D、F 每个效果都要一张图标或标记。

## 五、建议的顺序

1. **E 收摊计分演出**:不改数值,马上能让"凑组合"更爽,也方便真人试玩时看清分数从哪来。
2. **A 街型 + 品类升级**:补上"简单组合"这一档,让一局有方向。
3. **B 成长型秘诀**和 **C 改规则秘诀**各先做 3~4 个,同时给美术排图标。
4. 拿到真人试玩数据后统一调目标。
5. 视反馈再做 D、F。
